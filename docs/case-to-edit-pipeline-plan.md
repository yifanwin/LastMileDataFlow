## 本轮验收边界

- case1：几何、家具或障碍布局形成不同操作侧的差异，不能只是移远。
- case1.5：构造 A 侧狭窄、B 侧目标布局不利、C 侧相对合适的对比。真实 A 不可达、B 臂不可达、C 成功率高仍待验证。
- case3：目标接近、抬升或撤离相关区域出现具体障碍布局；数量多不等于机制成立。
- 保留原始任务假设。构造通过、case 成立、任务成功分别报告；未测保持 unknown。
- 不引入最小编辑、权限审批或人工成功标签；保留宽松物理配置及端点支撑检查。

## 验收顺序

1. 全套离线回归，包含实际 EGL、同候选格式修复、提议补图与检查补图。
2. 仅使用 Xera 独立密钥和 `gpt-5.6-sol`，采用聊天式接口 + JSON Schema；DMX 禁用。
3. 检查真实相机覆盖和前后图，不能只依据文件存在。
4. 在相同输入与图片上对照 `glm-5.3`，分别报告格式和职责遵守；不以通过数单独评价。
5. 如存在真实构造失败，保留失败类型和证据，不通过放宽物理门槛或修改旧结果绕过。

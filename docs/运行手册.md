# 最小运行路径

先按 [setup](setup.md) 安装和准备数据。全部命令使用当前仓库的 `.venv/bin/lastmile-dataflow`，不依赖 `PYTHONPATH` 或相邻工作树。

```bash
.venv/bin/lastmile-dataflow build-scenes --config <recipe.json> --run-id <scenes> --gpu <index>
.venv/bin/lastmile-dataflow evaluate-stations --dataset <scene-dataset> --assets-dir <assets> --run-id <calibration> --gpu <index>
.venv/bin/lastmile-dataflow collect-lastmile --dataset <scene-dataset> --assets-dir <assets> --calibration <calibration-run> --run-id <lastmile> --gpu <index>
.venv/bin/lastmile-dataflow build-bench --dataset <scene-dataset> --calibration <native-calibration> --output <bench> --policy-config <policy.json> --gpu <index>
.venv/bin/lastmile-dataflow evaluate-bench --benchmark <bench> --output <eval> --policy-config <policy.json> --gpu <index>
```

`build-scenes` 内部完成发现和资格检查，临时基线随构建结束清理。高级实验仍可直接使用 Python 的 discover/qualify/build 函数。
`evaluate-stations` 可传执行配置，使用 MolmoBot 时需要 native 控制场景和匹配相机；不能静默更换控制模式。
视频、深度和逐物理步日志用 `--record-video/depth/physics` 启用。
连续采集没有 `--calibration-only`，单独标定直接用 `evaluate-stations`。旧命令无别名，默认单卡串行、新 run。

benchmark 的 `--allow-uncalibrated-smoke` 仅检查启动，不成立困难 S0 评测。
读取带路径的配置用 `paths.read_config`；普通主 JSONL 用 `io.rows`。相对路径规则见 setup。

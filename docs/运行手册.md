# 运行手册（cuRobo + MolmoBot 合并版）

只给命令。`<空闲卡>` 自行查 `nvidia-smi` 后替换；不要用忙卡。

两个 worktree：

```bash
# 原始 val 基线
cd /data0/wenyifan/MoMaTrajGen/LastMileDataFlow/.worktrees/no-edit-lastmile-val
# 增强场景
cd /data0/wenyifan/MoMaTrajGen/LastMileDataFlow/.worktrees/procedural-obstacle-augmentation
```

## 环境（每个 shell 只做一次，cd 到上面任一 worktree 后执行）

```bash
# 首次：装 cuRobo 独立后端（标签 4ea77366ca48ee453e7df139e39fa6532af49f3b）
scripts/setup_curobo_v080.sh /data0/wenyifan/MoMaTrajGen/curobo \
  /data0/wenyifan/MoMaTrajGen/molmospaces/.venv/bin/python

export MUJOCO_GL=egl

```

后续每条命令前二选一（本 shell 内 export 一次即可）：

```bash

export WARP_CACHE_PATH="$PWD/outputs/dependencies/warp-cache"
export MPLCONFIGDIR="$PWD/outputs/dependencies/mpl"

# MolmoBot（VLA）

export MPLCONFIGDIR="$PWD/outputs/dependencies/mpl"
export HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1

```

## 一、cuRobo 后端

### A. 原始 val 场景

```bash
# 在 no-edit-lastmile-val worktree 根
# 配置 configs/no_edit/curobo_v080.json：radius_m=2.0，trials_per_station=5
RUN_ID="no-edit-v080-val103-cup30-$(date +%Y%m%d-%H%M%S)"
set -o pipefail
bin/lastmile-dataflow collect-no-edit \
  --assets-dir /data0/wenyifan/MoMaTrajGen/molmospaces_data/assets \
  --dataset-dir /data0/wenyifan/MoMaTrajGen/molmospaces_data/assets/scenes/procthor-10k-val \
  --config configs/no_edit/curobo_v080.json \
  --run-id "$RUN_ID" --houses 103 --targets Cup_30 --gpu-ids <空闲卡> --workers 1 \
  2>&1 | tee "outputs/logs/$RUN_ID.log"
# 删 --targets → val_103 全部任务；再删 --houses → 整个 procthor-10k-val
```

## 二、MolmoBot 后端

### A. 原始 val 场景

```bash
# 在 no-edit-lastmile-val worktree 根
# 配置 configs/no_edit/molmobot.json：radius_m≈0.7928，trials_per_station=5，1024×576
RUN_ID="molmobot-val103-cup30-$(date +%Y%m%d-%H%M%S)"
bin/lastmile-dataflow collect-no-edit \
  --assets-dir /home/wenyifan/wenyifan/MoMaTrajGen/molmospaces_data/assets \
  --config configs/no_edit/molmobot.json \
  --houses 103 --targets Cup_30 --gpu-ids 5 --workers 1 --run-id "$RUN_ID" \
  > "outputs/logs/$RUN_ID.log" 2>&1
# 删 --targets → val_103 全部支持任务；GPU 由 MolmoBot 自选，--gpu-ids 给候选池
```

### B. 增强场景

```bash
# 在 procedural-obstacle-augmentation worktree 根
# 正式入口：无需手工拷贝、无需首次 --resume

  --config configs/case_edits/no_edit_molmobot_case1_v000_final_stations.json \
  --run-id "no-edit-molmobot-final20-case1-v000-$(date +%Y%m%d-%H%M%S)" \
  --houses 103 --targets Cup_30 --gpu-ids <空闲卡> --workers 1
```


## 三、VLA S0→S1 连续导航 + 操作实验

```bash
# 在 no-edit-lastmile-val worktree 根；source 为已完成的 MolmoBot 采样 run
PYTHONPATH=src "$DATAFLOW_PYTHON" scripts/run_molmobot_station_transfer.py \
  --source outputs/no_edit/<已完成采样run> \
  --output outputs/diagnostics/transfer-<唯一id> \
  --start S0009 --goal S0023
# --output 目录必须不存在；--start/--goal 须 geometry=valid；固定 5 次 trial
```

```bash
# 配套：停在段上任意位置（fraction ∈ (0,1)）再操作，协议与上面逐项相同（同初态、同种子）
PYTHONPATH=src "$DATAFLOW_PYTHON" scripts/run_molmobot_station_path_transfer.py \
  --source outputs/no_edit/<已完成采样run> \
  --output outputs/diagnostics/path-molmobot-S0009-S0023-f50-<唯一id> \
  --start S0009 --goal S0023 --fraction 0.5
# --fraction 为段上比例：0.5=中点、0.6666667=2/3、0.75=3/4；--trials 默认 5
# 先加 --dry-run 只做几何与证据（101 点静态碰撞检查），不加载模型
# 两个脚本都在 no-edit-lastmile-val worktree；在 main 上会因相对路径找不到 SourceFileLoader
```

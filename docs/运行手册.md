# 运行手册

从本 worktree 根目录运行。先准备 ProcTHOR 场景及资产、RBY-1 XML/规划描述，按实际位置修改配置路径。当前尚未提供已验证的一键独立环境或数据下载器。

```bash
python -m lastmile_dataflow.cli --help
python -m lastmile_dataflow.cli discover-scene-datasets --config <recipe.json> --output <discovery.json>
python -m lastmile_dataflow.cli qualify-scene-datasets --discovery <discovery.json> --output <qualified.json>
python -m lastmile_dataflow.cli build-scene-datasets --config <recipe.json> --discovery <qualified.json> --dataset-id <name> --gpu-ids 0
python -m lastmile_dataflow.cli collect-no-edit --dataset-dir <scene-dataset> --assets-dir <assets> --run-id <run> --gpu-ids 0
python -m lastmile_dataflow.cli collect-lastmile-datasets --dataset <scene-dataset> --assets-dir <assets> --run-id <run> --gpu-ids 0
```

`collect-no-edit` 输入也是场景库，不能再传原始 ProcTHOR 目录。使用 MolmoBot 时显式提供策略配置以及匹配 native 控制模式的场景；不静默替换控制模式。
`--record-video`、`--record-depth`、`--record-physics` 为可选记录。
连续采集可传 `--calibration <run>`，或 `--calibration-only` 只完成逐点标定。当前单 GPU、串行、新 run，不保留旧 worker 队列、resume 和自动审阅。

```bash
python -m lastmile_dataflow.cli build-lastmilebench --dataset <scene-dataset> --calibration-dir <matching-native-calibration> --output <bench> --policy-config <policy.json> --gpu-ids 0
python -m lastmile_dataflow.cli evaluate-lastmilebench --benchmark <bench> --output <eval> --policy-config <policy.json> --gpu-ids 0
```

`--allow-uncalibrated-smoke` 只用于检查链路，不能声称困难起点评测成立。完整回归与真实 GPU smoke 分开，见 [tests](../tests/README.md)。

Python API 见 [README](../README.md#代码入口)。当前执行配置位于 `configs/execution/`，两个命令都调用 `workflows/collection.py`，没有旧采集 workflow 兼容壳。

## 3. 测试如何精简

最终结构与运行命令见 [tests](../tests/README.md)。

- 将混合的 `test_execution.py`、`test_foundation.py`、`test_light_dataflow.py` 按场景、控制、判定、数据与 workflow 拆归对应目录。
- 合并 tiny rendering、资产加载、失败隔离和停批测试到对应主题，避免按历史事故各建一个平铺文件。
- 共享简化场景 fixture 与 pick trace，删除重复轨迹生成；生命周期辅助函数直接接收待执行函数，不再转发无用参数。
- 删除只冻结默认值、示例配置内容、已删除参数不存在的测试；实际行为由配置和集成回归覆盖。
- 合并重复的非有限物理状态/初始穿透、begin 后禁止重新放置、Gaussian 成败权重和短 hold 超时断言。关键行为仍分别由接触、benchmark 初始化、地图与判定测试覆盖。
- 四个显式 smoke 移入 `tests/smoke/`，去掉历史步骤命名；真实规划与 FOV 脚本显式接收 GPU。
- 权重 smoke 不再为启动依赖 Git 运行元数据。FOV 脚本入口检查时发现同目录文件名遮蔽 cuRobo 包，已将 rollout 脚本改名为 `curobo_rollout.py`。

为保证递归发现，测试目录增加必要的包标记，导入统一使用 `tests.helpers`。
`.gitignore` 中数据目录规则由 `data/` 改为 `/data/`，只忽略根目录真实数据，避免把新增 `tests/data/` 也忽略。该修正也让此前被同名规则隐藏的 `src/lastmile_dataflow/data/` 子模块恢复为 Git 可见的未跟踪文件；其内容未修改，也未代用户暂存或提交。
没有新增兼容壳、测试框架、旧路径转发或附件索引。

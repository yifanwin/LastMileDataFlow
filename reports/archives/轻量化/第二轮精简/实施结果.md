## 1. 实际删掉和缩短了什么

### 构造时已确定的属性，使用时不再补缺

- `timings`、`pick_initial`、`last_legal_torso_target` 直接读取；真实可选状态仍以 `None` 表示。
- `open_joint`、`manip_base_target`、机器人 stationary cache、固定底盘目标及 `Simulation.spec` 在构造时明确初始化。
- 当前唯一 V2 planner 直接提供 `h_step_limit`；删除旧的无躯干适配分支、无用的 `h` 传参和恒真的能力标记。
- 轨迹关节顺序与维度在进入执行器时检查一次，不在每个 waypoint 重建名字列表。
- 静置函数保留入口准备检查，不在同步循环的每个物理步再次检查同一生命周期状态。

### 只传真正需要的数据

- `Simulation._submit()` 只返回 command，不再传递两个恒为 `None` 的编号。
- 删除 `vector(...).copy()` 的重复复制；原始动作与实际下发动作仍分别保留。
- 用显式局部变量替代 `locals().get()`。
- 删除 `robot_descriptor()`、未使用的 reach helper、旧 IK 空诊断包装、`construct()` 和只用于拒绝其他取值的内部 `workers/resume` 参数。
- 未知配置字段仍由 dataclass 构造器拒绝，错误类型为原生 `TypeError`。

### recorder 不再收一堆最终不用的参数

删除 `intent()`、`record_step()`、`strategy`、`frame_index`，以及 `finish()` 中未被消费的 results/extra 参数。

执行器在下发前写入 phase；Simulation 在初始状态及实际控制间隔结束时调用 recorder。轨迹与 PNG 只有一个记录位置，视频消费已有帧，不再通过“文件已存在就跳过”掩盖重复写。

由此也删掉了调用方仅为旧接口准备的 before/after 全状态、动作列表和临时字典。实际输出仍满足 **N 个动作对应 N+1 个状态**；部分执行间隔仍记录真实发生的物理步。

### 配置、编号和统计少绕一圈

- attempt/episode 编号使用新 run 内共享的串行计数，不再每次重读 JSONL。
- 同一场景机器人配置在 run 准备时解析，执行时复用；场景构建各阶段的 geometry/robot 在循环外加载。
- 删除非必要的开关类型穷举、摄像头别名字符规则、内部列表逐元素格式检查。
- `ExecutionConfig` 的数值约束改为明确字段，不再根据字段名后缀推断规则。
- 标定按站位组织 trial，避免为每个站位重新扫描全部 trial。
- 删除当前生成端不产生的 `success_rate` 兼容核对；实际困难选择仍由 trial 计数计算。

### 异常处理只保留有实际作用的边界

episode 上下文由显式 `root/station/attempt_id` 传入，不再使用函数签名反射、备用上下文入口及内部返回 dict/身份复查。克隆 Simulation 交给 episode 资源范围关闭，不在 attempt 正常结束时重复关闭。

未强行合并所有异常捕获：操作阶段需要产生任务终止结果，外层仍须处理初始化、记录和关闭阶段异常。这些不是对同一正常结果重复审核。RPC 失联、GPU/存储错误分类与主动中断传播保留；没有新增罕见错误情况。

## 3. 保留项与顺手修复

保留动作合法性、限位 yaw、控制节奏、躯干反馈规则、状态迁移和构建回滚、抓取保持/接触/滑移判据、导航到达条件、外部标定匹配和完整性、统计分母。

静置稳定性开关会改变物理接受规则，因此仍在配置入口检查一次；没有把配置字符串 `"false"` 当作合法物理开关。cuRobo 内部异型对象的属性检查、目标 SDF/携带物拟合修正、模型算子和必要帧缓存未盲删。

标定内部未增加“已验证对象”或新的 rate 中转层：剩余少量直接重算比新增抽象更轻。

**基线发现并修复一个原有错误：** `ThorLibrary.retrieve()` 中 `os.scandir()` 的局部变量覆盖资产结果列表，导致未注册资产扫描后执行 `.append()` 失败。仅重命名扫描变量，保留原检索逻辑；原有回归已覆盖。

# 按六步流程比较旧方案与当前默认

结论：当前默认可作为有真实任务证据的科研实验基线，但碰撞表示尚未全面验收。已知底盘误拒、合并凸包的重叠内部符号问题仍存在；不能把规划无解直接当成物理不可达。当前默认仍为新 Panda 球表 + merged_hull；box_cuboids 为可选项，关闭碰撞只用于实验副本。

## ① 几何来源

原始物理几何仍来自 MuJoCo MJCF、机器人和场景资产。Panda 初始规划描述来自本地 MolmoSpaces，实体几何来自 robosuite；项目自行改造球覆盖。RBY 球来自 MolmoSpaces 外部资产配置。环境直接读取场景碰撞 geom，未从 RGB 重建。库提供查询，不保证项目输入的球表或导出几何天然正确。

## ② 机器人与环境近似

| 部位/路线 | 旧方案与问题 | 当前默认/处理及限制 |
|---|---|---|
| Panda 底盘 | 12 个半径 0.21 m 的大球，侧向约外扩 10.7 cm，实体离家具数厘米仍误拒 | 项目块覆盖 ILP 生成 51 球；侧向仍外扩约 3.6 cm、顶部 6.2 cm，近站位误拒未消除 |
| 固定柱/升降柱 | 各 8 球；按 A 阶段口径，含 buffer 侧向外扩约 14.8/13.9 cm | 项目扇区覆盖生成 19/15 球，侧向约 2.1 cm |
| Panda link0 底座 | 1 球漏覆盖约 6 cm 实体 | 35 球覆盖，外扩约 3.2 cm |
| Panda 总体 | 旧球既可能过宽也可能漏实体 | 当前 141 实体球 + 40 附着槽；并非全机器人都重新拟合 |
| RBY-1 | 外部球表与忽略对 | 仍沿用；86 表内球中启用 78，另 80 附着槽。未证明未列入的掌部、头部等由邻球充分覆盖 |
| 上游旧 RBY 环境 | 对象级长方体：由 object pose 与 aabb_size 构造；可能把桌下和凹处空隙堵住 | 当前两机器人统一走逐 geom 导出，不是按整件家具一个大盒子 |
| 本项目早期环境 | 原始 mesh 直接拼接，存在大量不封闭面，自由空间被判成内部 | 每个 mesh geom 转闭合凸包，primitive 三角化，再拼成一个 mesh；保留 geom 间空隙，但单 geom 凹处填平，重叠壳问题仍在 |
| 曾尝试逐 geom 独立 mesh | 采样几何查询改善，但 mesh 数导致运行过慢 | 已撤回，不是默认 |
| 可选近处 Box | 不是旧对象包围盒路线 | 原生 Box 精确保留尺寸/位姿，1.5 m 内最多 128 个独立 Cuboid，其余合并 mesh；未成为默认 |

原始网格的问题是输入不满足可靠内外判断条件。历史文档曾以射线奇偶解释，后续已纠正为本机 Warp 最近命中面朝向投票；不要重复旧机制解释。

## ③ 碰撞查询

当前使用 cuRobo 原生 sphere–mesh / 可选 sphere–OBB / 自碰撞 sphere–sphere。本项目负责导出、坐标变换、接触掩码和 checker 生命周期。目标、把手与环境分开，允许接触仅作用于指定目标/把手 Link 对。此前目标复用错绑、小目标 no-hit 查询范围过小也会造成错误；已有修复，不能把这些软件问题归因于实体形状。

TrajOpt 使用 swept 检查，内核固定 3 个 sweep steps；metrics 为离散查询，不是严格连续无碰撞证明。当前未使用环境 ESDF，也未部署 CoACD。两者是历史候选，不算已完成改进。

## ④ 运动规划

球外扩会直接使起点不可行，增加 IK 种子或重试不能修好同一个被拒起点；收紧几何后也可能选中不同抓取候选，导致后续求解失败。规划成功只说明近似几何及采样判据通过，不能直接推出物理可执行。优化激活距离 1 cm 与球 buffer 是不同参数。

## ⑤ MuJoCo 物理执行

物理仍使用原始碰撞 geom，不使用规划球替换实体。2026-11-04 的关闭规划碰撞实验仅改冻结实验副本，三站 9 trial 中 8 次进入执行、1 次成功。2026-11-05 诊断进一步确认七次跟踪超时中：六次参考底座进入桌子约 5.96–12.89 mm，实际被接触挡住；另一次末端残差 10.38 mm，略超 10 mm 门槛。均因单点 120 步不收敛停止，不是自动碰撞急停。

所以起点实体有间隙、球误拒，与后续无碰撞约束轨迹发生真实碰撞并不矛盾。该实验没有证明原站位绝对无可行轨迹，也没有证明仅缩球就能成功。

## ⑥ 效果、性能与可用性

- Cup_30 同追踪单元：P1 修复后旧球/原始网格基线 37/60，当前默认 46/60；可选 Box 为 44/60。提升来自多项累计变化，不能全归因于一个修复。
- 当前默认仍在 S0022/S0030/S0038 均 0/3：同状态实体间隙 1.38/19.07/16.18 mm，但底盘球判碰撞，属于已确认起点误拒。
- 七站冻结规划：merged_hull 170.9 s、8/21 lane 成功；近处 Box 128 槽 173.0 s、12/21。固定 42 trial 则两者均 12 次任务成功，Box 尚无稳定整体优势。
- 逐 geom 独立 mesh 曾让 val108 pre-close 从约 25 s 升至 278 s、val105 从 28 s 升至 245 s，预算超时而撤回。
- 仅换底座球、同求解次数约慢 1.2 倍；球数更多换来了更紧且补足覆盖的近似。Box 槽位减少有收益，但 S0012 相同求解次数仍约慢 3 倍。
- 上述为历史整次规划/执行结果，不是单次碰撞核延迟；本次没有新 GPU 测量。无控制帧接触也不能证明帧间无接触。

可继续使用：冻结当前默认做局部科研对照、保留物理执行证据，并单列已知表示误拒。
尚不可宣称：完整可靠碰撞模型、所有失败站位物理不可达、两机器人全身覆盖已验收、跨场景无漏检或高成功率采集主链已闭环。
下一步优先处理已确认底盘误拒，同时保持轨迹碰撞检查；用已有参考实体碰撞反例检查新表示。环境重叠符号问题按已有反例验证实际有限半径球的漏检影响，再决定局部独立几何或距离场路线；RBY 需单独核对未启用部位覆盖，不能借用 Panda 验证结果。

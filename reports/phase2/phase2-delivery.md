- 零编辑、移动、旋转、不同检查点身份、撤销和离线冻结恢复。

## 验证中发现的问题与保留失败

- 真实 box 的水平顶面不一定沿资产局部 Z 轴。改为检查任一局部轴与世界竖直的关系，仍用真实碰撞面，不用家具整体包围盒替代桌面。
- 删除物体时，接触在下方的桌子不应被误认成依附物。依赖检查增加上下关系，metadata 父子关系仍只作为保守拒绝线索。
- 构建会话的连续执行误调用最初可能落入异常回滚分支。改为在保存检查点前直接拒绝，防止绕过阶段一生命周期。
- 初版对 NAS 中大量依赖逐文件 resolve/hash，扫描过慢而人工中断。静态检索改为引用粗筛，单资源核验保留显式慢路径；冻结模型摘要覆盖实际编译内容。
  [初版日志](logs/phase2-real-smoke-v1.log)保留，不计为通过。
- 冷启动的 Potato 样例在末尾窗口最高速度约 **0.03367 m/s**，超过固定的 0.025 m/s 阈值，虽已正确支撑也没有放行。
  随后修复在整个 request 的 300 s 预算内未完成，记录为 `budget_exhausted`。
  [冷启动记录](checks/phase2-real-smoke-cold.json)、[日志](logs/phase2-real-smoke.log)和原失败 build 保留。
  没有为 Potato 放宽阈值。后续选用符合协议的 SaltShaker，并使用本地冻结输入绕过远程网格冷加载。
- CLI 的原生加载/NAS 等待增加隔离进程监督；同一 request 的期限与消耗跨候选/房屋累计，不通过新建 build 重置。

失败输出仍位于 `outputs/builds/phase2-v1-train0-zero/`、`outputs/builds/phase2-final-train0-zero/`，没有覆盖。

## 当前边界

构建核心可交接，但不是通用编辑器，也不是全类别物理保证。
平面 mesh 使用水平三角形与 5×5 射线采样，可能保守拒绝窄面，不能保证检测任意小洞口。
固定协议目前只有有限真实样例试跑，不能解释为全资产校准。
新增资产仅来自声明有加载/摆放证据且实际可编译的有限池；本次没有发布未经真实验证的通用资产池。

下一步应补真实合格资产池、把手语义来源与后三类 case 的物理覆盖；
需要视觉判断时再接实际模型，阶段三再验证站位差异、抓取困难和任务成功。

## 现象

- 2,756 个回合 0 成功。前 100 万样本里双指接触率 6–11%，之后降到 0；无碰撞比例 0.21 → 1.00，回合全部跑满 1000 步超时。
- 末期回报约 5–6，几乎全部来自 position + orientation 的势函数差分（靠近一次性得分），closing/grasp/lift 全为 0。策略收敛到“靠近后悬停、不接触”的局部解。
- 熵 4.2 → −0.16（entropy_coef=0，无熵约束）。value 正常：EV 0.8–1.0，value loss 很小。

## 按 pipeline 分层结论

| 层 | 结论 | 证据 / 影响 |
|---|---|---|
| 训练流程（主因） | KL 早停让每轮几乎只更新 1–3 步 | 184 轮全部触发 KL 早停；只有 1 轮完成过第 1 个 epoch；平均 3.6 个 minibatch；300 万样本共 666 次梯度步，是计划上限 29,440 的 2.3%，SAC 对照为 2.3–3.9 万次 |
| 网络 + 优化器（主因的根源） | 单步 Adam 更新的 KL 就超过 0.02 | 第 1 轮初始网络 max_minibatch_kl=0.034，后几轮 0.024–0.040。Adam 早期步长≈lr×sign(g)，lr=3e-4 对状态相关 log_std 的输出头一步就移动过多；默认初始化（未做 0.01 增益的输出层、未用独立 log_std 参数）放大这一点 |
| 算法（加重因素） | 无熵正则 + 状态相关 std，熵塌缩；std 小后同样步长 KL 更大 | update 97 一步 global_kl=0.235；后期 actor_grad_norm 升到 7–12；SAC 有 α 自动调节（target −7）一直保持探索 |
| 训练参数 | 样本预算对 PPO 太小，回合过长 | PPO 典型需要比 SAC 多 1–2 个数量级样本；50 s=1000 步回合，300 万样本只有约 3,000 个回合，而成功回合约 85 步；γ=0.999 对 85 步任务偏长，价值目标方差大 |
| 奖励 / 输出 | 本身可学（SAC 已学会），但对弱探索不友好 | 势函数靠近奖励一次性给完；接触桌面/方块非指部持续 −1/步，抓取事件 +3 只给一次 → 在只有几百步梯度的情况下，“不碰”比“去抓”更容易被梯度推到 |
| 终止处理 | e4c4654 把超时截断当成终止（8399457 已修复） | 每 1000 步才出现一次、且截断时 V≈0，影响小；SAC 当时同样有此问题仍能学会，不是主因 |
| 输入 | 无运行均值归一化，最大值约 7（见 24 号审计） | 量级可接受，次要因素 |

一句话：PPO 没学会的直接原因是“几乎没有训练”——KL 早停阈值相对单步更新量过严，每轮只走 1–3 步，再叠加熵塌缩，策略在几百步梯度内被推到不接触的悬停解。

## 迁移到 rl-cup 时建议（未验证）

1. 优化：自适应学习率（rsl_rl/mjlab 做法：desired_kl≈0.01，KL 过大降 lr、过小升 lr），去掉逐 minibatch 硬停；或 lr 1e-4 并把早停阈值放到 1.5×target_kl 且只在 epoch 结束判断。
2. 网络：Actor 用独立可学习 log_std 参数（初值约 log 0.6–1.0），输出层正交初始化增益 0.01；加 entropy_coef≈0.005 或对 log_std 设下限。
3. 输入：加运行均值/方差归一化（统计量随 checkpoint 保存，并给近常量维设最小 std）。
4. 规模：每卡环境数尽量加大（受 nconmax/njmax 限制），rollout 24–32 步；预算按千万级样本规划，γ 0.99–0.995，回合缩短到 10–15 s。
5. 先在 S0246 固定站位短跑，看 epochs_completed、梯度步数、熵曲线是否正常，再看接触率是否持续上升。

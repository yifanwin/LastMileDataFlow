## 1. 目标

第一版噪声（停靠 5 cm/5°、目标观测 5 mm、动作 0.1）下成功率随 σ 几乎不变，$Q_{\text{phys}}$ 在 σ 维度没有区分度。本次把噪声放大到 **停靠 15 cm / 15°、目标观测 15 mm（动作仍 0.1）**，重采标签、重拟合五头、出图并与第一版对比。按用户 2026-11-23 决定，结果只看正对目标的 0° 航向。

## 3. 结果（0° 航向，冻结 s2r1，均值动作）

| 指标 | 第一版噪声 | 大噪声 |
|---|---|---|
| 实测严格成功，σ 五层 | 0.832 / 0.839 / 0.827 / 0.820 / 0.798 | 0.834 / 0.803 / 0.745 / 0.665 / 0.536 |
| 每条抓法 μ(σ=0) − μ(σ=1)，站位均值（p10/p50/p90） | 0.041（0.016/0.025/0.105） | **0.388**（0.303/0.407/0.481） |
| $Q_{\text{phys}}$（Max 选抓）均值 / 标准差 | 0.868 / 0.199 | 0.750 / 0.179 |
| $Q_{\text{phys}}$ p10 / p50 / p90 | 0.686 / 0.949 / 0.970 | 0.510 / 0.823 / 0.893 |
| $Q_{\text{phys}}$ ≥ 0.9 的站位占比 | 0.775 | **0.049** |
| $Q_{\text{phys}}$（均匀选抓）p10 / p50 / p90 | 0.473 / 0.930 / 0.958 | 0.407 / 0.782 / 0.866 |
| $U$ 均值 | 0.027 | 0.033 |
| test（24 站）Brier / NLL / 站位 Spearman | 0.053 / 0.209 / 0.744 | 0.134 / 0.420 / **0.892** |
| calibration（8 站）站位 Spearman | 0.643 | 0.762 |

Brier/NLL 变大是因为基率从 0.86 降到 0.74、标签本身更不确定，不代表拟合变差；站位排序 Spearman 提高。

**结论**：大噪声下 σ 维度出现明确区分（每条抓法从 σ=0 到 σ=1 平均掉 0.39，第一版 0.04），$Q_{\text{phys}}$ 不再在 0.95 附近饱和（≥0.9 的站位从 78% 降到 5%），能在“都能做”的站位之间排出抗扰动程度。空间形态不变：外缘与远端低、内侧高；$U$ 仍集中在边界。

## 9. s2r1 排查：成功率随 σ、三类噪声是否生效（2026-11-23T11:15+08:00）

s2r1 σ 上限 0.1→0.25→0.5→0.75→1.0 分别在 2.84 / 4.97 / 7.03 / 8.97M 扩档，训练严格成功全程 0.52–0.54。

- **噪声生效**：停靠抖动按记录的实际底盘位姿核对，σ 各档 XY 最大偏差 0.98 / 1.98 / 2.97 / 3.95 / 4.99 cm、yaw 最大 0.97–4.87°，与 5 cm·σ、5°·σ 上界一致；动作扰动与观测偏差无逐回合日志，按代码路径（`StationEnv.step → execute_action`、`flat_state` 的 `target_offset`）生效，σ 升高时超时下降、外指/掌接触上升也与动作扰动相符。
- **“高噪窗口反而更高”是统计口径伪影**：扩档后的一段时间里，高 σ 回合都是新 reset 的，长回合（不可达站位悬停到 400 步超时）还没结束，结束回合中不可达站位占比偏低。排空旧回合后（>10.3M）低噪窗口 0.549、高噪 0.539，不可达占比 0.219 / 0.212，两者一致。课程门槛判定受此影响偏早扩档，但每档 ≥1M 且成功率保持，未造成退化。
- **σ 影响幅度小**（10.3M 后、IK 可达站位，σ<0.33 / 0.33–0.67 / ≥0.67）：距目标 <0.6 m 0.73 / 0.69 / 0.66，0.6–0.8 m 0.73 / 0.74 / 0.73，≥0.8 m 0.60 / 0.60 / 0.57；不可达站位约 0.05。近距离站位对扰动最敏感（约 −7 个百分点），其余 ≤3 个百分点。
- **对质量图的含义**：当前噪声幅度（停靠 5 cm/5°、观测 5 mm、动作 0.1）下 σ 积分与 σ=0 的差别有限，Q_phys 主要由可达性与接触难度决定；若要拉开“鲁棒程度”的差异，后续可增大停靠抖动幅度（如 10–15 cm）重采标签，先按现幅度完成阶段三。

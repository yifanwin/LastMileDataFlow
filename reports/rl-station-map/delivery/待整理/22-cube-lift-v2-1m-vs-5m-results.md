## 结论与统计口径

两次训练均完成预算，500万条提高了训练回报，但**没有形成稳定的对准、闭爪、双指接触与抬升策略**。最明确的证据是：所有健康、完全非随机预热的训练回合中，closing和grasp奖励均为0；500万run最后50万条对应的514个完整训练回合，成功0次，而平均回报仍为14.97，主要来自张开奖励15.15。

本次只核查已有metrics.jsonl、TensorBoard事件和best/latest checkpoint，没有启动新训练或独立策略rollout。下述成功率都是训练过程中不同版本Actor的完整回合统计，不是某个checkpoint的独立成功率，不代表泛化。表格均值直接按回合重算，不是TensorBoard平滑末值。

两run固定同一源码551ac842913d8c91d9fc0735d5192ca443fe7a1f、同一mjlab版本、相同任务与seed42。已逐字段比较checkpoint中的有效配置，唯一差异为training.max_transitions：1,000,000→5,000,000。都是从头训练，无resume；CUDA0–3各128环境、预热20,000、Replay100,000、batch256、每128条更新一次均相同。它们是两个独立异步训练run，500万run不是100万run的延续。

## 回报、损失与截图解释

最后100个健康非预热回合的奖励均值：

| 奖励分量 | 100万run | 500万run |
|---|---:|---:|
| position | +1.410 | +0.780 |
| orientation | -0.251 | -0.170 |
| collision | -5.260 | -1.640 |
| success | +0.300 | 0 |
| opening | +5.510 | +14.266 |
| closing | 0 | 0 |
| grasp | 0 | 0 |
| return | **+1.710** | **+13.236** |

return的提升来自张开奖励增加和碰撞惩罚减少，未来自闭爪、对准后的双指接触或稳定成功。最后50万条的回报分解更明确：opening +15.153、position +0.494、orientation -0.135、collision -0.537、其余0，合计约14.974。

代码在d>4cm时逐步支付0.02*max(-a_g,0)，无需取得接近进度，1000步理论最高20。现有结果支持“长期远离抓取门限执行张开动作，可以获得可观回报”这一奖励捷径判断。closing=0只证明“d<3cm且θ<10°且正闭爪动作”的交集从未获得奖励，不能仅凭日志区分是位置/角度门限没进入，还是进入后未给正闭爪动作；grasp=0也不表示全程无双指接触。原始first_contact_time_s显示两个run分别有4/51个非预热回合曾双指接触。

success与grasp奖励条件不同：success看任一物理子步双指接触并抬升0.0086m，不要求对准；grasp看最后子步双指接触且d<3cm、θ<10°。因此success>0而grasp=0并不矛盾。这些稀少成功是否属于稳定、对准后的抓取，仍需真实rollout与轨迹/视频核查，不能由聚合日志推定。

损失与探索按实际TensorBoard事件核对：

- 100万末次30s更新区间的actor loss=-11.459、critic loss=0.09894、entropy=4.664，alpha=0.04654。
- 500万末次区间actor loss=-17.382、critic loss=0.00415、entropy=-2.377，alpha=0.002505。critic区间均值最高2.591，出现在3,090,048条附近；后期存在明显尖峰和波动。
- actor loss更负、critic末值更低，都不能证明抓取能力提高；它们衡量当前奖励与价值估计下的优化。alpha降低、entropy下降表明策略分布比早期更集中，结合奖励分解可见其集中并未带来稳定抓取。连续动作微分熵允许为负，负值本身不是报错；本轮不把这些波动直接判为数值发散。
- 截图的train曲线为刷新区间完整回合均值再经界面平滑，样本数与本报告全程/最后100回合统计不同。截图末点与本报告均值不必一致。
- warmup标记是“该回合曾包含随机动作”。虽然全局随机预热仅20,000条，首批512个并行回合延续很久，warmup曲线可到约50万条附近。它不是额外50万条纯随机预热，更不是最终Actor的评估。500万run的混合warmup回合有2次成功，不并入9次非预热训练成功。

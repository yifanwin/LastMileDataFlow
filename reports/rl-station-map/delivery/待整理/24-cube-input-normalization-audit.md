## 目标与数据边界

逐维检查实际送入 Actor/Critic 的 65 维观测的均值、总体标准差（ddof=0）、最小值、最大值、全零/常量、NaN/Inf 和尺度差异。接触力不在这套输入中，因此没有力输入的统计。

原训练没有保存逐步观测或 replay，checkpoint 只保存参数、优化器、配置与元数据。本次使用 checkpoint 内的有效配置和原运行提交 `551ac842913d8c91d9fc0735d5192ca443fe7a1f` 的当前源码重新采样；不是原 100万/500万条训练数据的全量统计。

随机均匀动作和 1m/5m 的 best/latest 共五组，每组 32 个并行环境、1000 个控制步、seed=20261117，模型组使用 stochastic Actor。每步在选动作前保存真正进入网络的观测，结束槽位重置后继续采样。另存结束时观测，避免与网络输入混合。环境每控制步包含25个物理子步，物理 dt=0.002 s。物体、站位、成功协议、动作尺度沿用原配置，不更新权重。相邻观测有相关性，32,000条不代表独立样本数。

GPU 0 跑 random 和1m-best，GPU 1/2/3 分别跑1m-latest/5m-best/5m-latest。所有五组完成后停止 GPU 0 循环，避免重复采样已由其他GPU完成的条件；其控制台退出码143来自这次主动停止，五组统计与原始数组均已完整保存。没有修改运行源码、训练配置、归一化或已有模型。

- 160,000条网络输入与272条结束观测均无 NaN/Inf，五组 unhealthy 均为0。
- 五组输入合看，没有任何一维始终为0。3个尺寸维度全为0.04 m，是本次固定方块尺寸造成的常量。
- random、5m-best、5m-latest 的方块旋转6D索引2/5、角速度X/Y全为0。这对应方块没有发生倾斜；1m-best/latest这些维度发生变化，排除了它们在观测代码中永久写死为0。不能只据个别组全零删除这些输入。
- 使用底盘观测位置和底盘位姿重建方块世界位置，五组最大逐坐标误差均为4.7684e-7 m。抓取位置误差与独立计算 `R_base^T * (p_cube - p_tcp)` 的最大差为0；底盘旋转正交误差最大4.7684e-7。没有发现世界位置的大数值错误混入底盘位置输入。这里检查了位置变换与旋转正交性，没有独立验证全部速度估计的物理精度。
- 观测整体最大绝对值7.00176，位于1m-latest的方块角速度Y，范围[-6.51938, 7.00176] rad/s；不是位置坐标出现数千或更大的异常数值。这是有限值，不代表已验证其碰撞动力学精度。

## 归一化与尺度

当前是部分字段固定缩放：旋转误差/pi；机械臂q/3.14、qdot/3；升降位置按模型上下限映射，升降速度/0.05；夹爪开度/模型最大开度，夹爪速度/0.2。位置、尺寸、物体与TCP速度保持物理数值，姿态取旋转矩阵前两列。无运行均值/方差标准化，无统一输入裁剪，网络也没有BatchNorm/LayerNorm。

升降速度缩放后最大绝对值2.89382，换回物理量约0.144691 m/s；夹爪速度缩放后最大绝对值约1.8924，换回两指相对速度约0.37848 m/s。它们超过缩放参考尺度；指令速度上限不是实测关节速度的硬裁剪。这不能直接判为坐标错误或物理异常，说明当前缩放没有保证单位范围。升降位置输入也有轻微超出[0,1]的情况，现有代码没有裁剪实际关节位置。

尺度差异存在：5m-latest升降速度标准差0.89744，位置误差三个分量约0.0626–0.0659（相差约14倍），方块XY线速度约0.00493–0.00733（相差约122–182倍）。静态方块竖直速度标准差7.7138e-8，与升降速度相差约1.16e7倍；其中很大部分是近静态量与运动量的差异，不能把这个倍数直接等同为归一化错误或训练失败原因。

本次发现的是固定/近固定输入、未缩放速度，以及超过固定参考尺度的实测速度；没有测量网络对各维的敏感度，不能由输入数值单独证明网络过度关注某个特征。若后续引入标准化，应对常量与近常量维度设置明确的最小标准差，避免放大数值微扰；统计参数须在训练/采样/评估间保持一致，并保存到新checkpoint。本次只检查，不改归一化。

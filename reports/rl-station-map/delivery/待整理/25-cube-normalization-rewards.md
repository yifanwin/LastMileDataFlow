## 目标与实现

在 `.worktrees/rl-cube-contact` 调整方块任务输入与奖励。按后续指令将碰撞惩罚改为−1，训练预算改为3,000,000条健康transition。保留原有工作区文档改动，不启动训练。

65维观测顺序、维度和底盘坐标系保持不变；抓取位置误差三维向量除以0.02 m，原始旋转误差三维向量除以20°（0.3490658503988659 rad）。保留方向，不裁剪，误差模在容差处为1。尺度由共享常量供 `flat_state` 和 `FLAT_FIELDS` 使用。奖励的距离与角度、上一步误差仍为原始米和弧度；其他输入尺度保持原样。输入定义随checkpoint保存，旧尺度65维与旧45维checkpoint均不能加载到新任务。

接触协议的七个奖励分项顺序为 `position, orientation, collision, success, closing, grasp, lift`。采样、replay、回合记录和TensorBoard共用分项名称；删除 `opening` 及其专用配置，新增 `reward.lift: 1.0`。

## 最终奖励与边界

所有奖励每策略步计算，不乘策略步长。`d` 为TCP抓取位置误差模，`θ` 为原始旋转误差模（rad），`a_g` 正值闭爪、负值张开。

| 分项 | 公式与条件 |
|---|---|
| 位置 | `10 × (d_previous − d_current)` |
| 旋转 | `0.5 × (θ_previous − θ_current)` |
| 碰撞 | 任一物理子步发生被监测非法碰撞时−1；同一步不按接触数或子步数叠加 |
| 成功 | 首次成功+30，策略步末终止回合 |
| 闭爪 | `d < 0.03 m` 且 `θ < 20°` 时，`0.05 × max(a_g, 0)` |
| 双指接触 | 同一距离、角度门限内，双指同时接触时+0.05 |
| 抬升 | 双指同时接触时，`1.0 × (Φ_current − Φ_previous)` |

按用户确认，`Φ = clip((z_cube − z_initial) / H, 0, 1)`，`H = success.lift_m = 0.0086 m`。双指接触时上升加分、下降扣分；抬升奖励没有额外位姿门限。每步无论是否接触都更新上一时刻Φ，避免重新接触追补未接触期间的高度增量。局部reset只清零指定槽位的上一时刻Φ，全量reset全部清零；读取观测不会更新Φ。

双指接触、闭爪和抬升塑形使用策略步最后一次原生物理采样，左右指法向力均须严格大于1e-6 N。成功沿用v2：同一个原生物理子步双指承力且相对回合初态抬升至少0.0086 m，即锁存成功；不增加保持、姿态或离支撑条件。物理子步dt=0.002 s，每策略步25个物理子步。保留既有碰撞监测、失败与健康判定。
